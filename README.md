# LoanManagement

Initial solution structure for the Loan Management System.

## Projects

- `LoanManagement.Core`: ASP.NET Core MVC application and Razor Views.
- `LoanManagement.DL`: Data-layer interfaces and repository implementations.
- `LoanManagement.Utility`: Shared constants and helper utilities.

The solution contains exactly two application database tables:
- `dbo.Customers`
- `dbo.EMICollections`

Loan account numbers are generated by SQL Server using `Seq_LoanAccountNo` and the `LN` prefix.

## Open and run

1. Extract the ZIP.
2. Open `LoanManagement.sln` in Visual Studio 2026.
3. Check the SQL Server connection string in `LoanManagement.Core/appsettings.json`.
4. Run `Database/CreateLoanManagementTables.sql` in SQL Server Management Studio.
5. Set `LoanManagement.Core` as the startup project.
6. Build and run.

This is the initial project scaffold. Login, customer workflows, repositories, and EMI collection behavior will be implemented in subsequent steps.

## Security note

Do not store a plain-text admin password in appsettings.json. The placeholder `PasswordHash` must be replaced with a securely generated password hash before implementing authentication. Aadhaar, PAN, customer photos and signatures require restricted access and secure handling.
